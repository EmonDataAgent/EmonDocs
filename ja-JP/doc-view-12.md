## 1. はじめに

AI 大規模モデルは Agent の基盤となるインテリジェントエンジンです。Agent は実行時にモデルをバインドする必要があり、モデルは自然言語理解、論理推論、SQL 生成、レポート生成などのコア機能を担当します。モデルモジュールを使用すると、プラットフォーム内で Agent が呼び出し可能な大規模モデルを一元的に設定および管理できます。

## 2. モデルの追加

### 2.1 追加画面へのアクセス

特権管理者またはモデル管理権限を持つ開発者として、「管理ポータル > モデル」にアクセスし、右上の「モデルを追加」ボタンをクリックして、モデル追加ダイアログにモデル関連の基本情報を入力します。

### 2.2 基本情報

| 入力項目 | 説明 |
| --- | --- |
| API 呼び出しプロトコル | 追加するモデルに適合する API 呼び出しプロトコルを選択します。<br><br>現在、以下の2つのプロトコルをサポートしています：<br><br>- OpenAI 互換プロトコル<br>- Azure 互換プロトコル |
| ApiKey | 認証に使用する、モデル公式から提供された API キーを入力します。 |
| EndPoint | モデルサービスの API インターフェースアドレスを入力します。 |
| API-Version | Azure 互換プロトコルを使用する場合にのみ入力が必要です。 |
| モデル名 | モデルサービスプロバイダから提供された公式モデル名（model name）を入力します。<br><br>「モデル名を取得」をクリックすると、自動的に取得できます。 |

### 2.3 接続テストと保存

入力完了後、「接続テスト」をクリックして API 接続が正常かどうかを検証します。テストに合格した後、「保存」をクリックしてモデルの追加を完了します。

## 3. モデル管理

### 3.1 モデルの分類

追加されたモデルは、追加場所に応じて「パブリック」と「マイ」に分類されます：

- 「パブリック」タブで追加されたモデルは、全員が公開して使用できます。
- 「マイ」タブで追加されたモデルは、作成者本人のみが閲覧・使用できます。

### 3.2 モデルの操作

モデルリストには追加されたすべての大規模モデルが表示され、既存のモデルに対して以下の操作が可能です：

- **検索**：上部の検索ボックスを使用して、モデル名で目的のモデルを素早く特定します。
- **接続テスト**：対象モデルの右側にある「... > 接続テスト」にホバーしてクリックし、モデルの API 接続が正常であることを検証し、Agent が正常に呼び出せることを確認します。
- **削除**：対象モデルの右側にある「... > 削除」にホバーしてクリックし、不要になったモデルを削除します。

## 4. 注意事項

1. **免責事項**：帆軟 は大規模モデルの推奨リファレンスと接続方法のみを提供し、大規模モデル自体の問題については責任を負いません。
2. モデルは削除すると復元できません。操作前に Agent に参照されているかどうかを確認してください。
3. `ApiKey` と `EndPoint` は機密情報です。漏洩を防ぐため、適切に保管してください。
4. ネットワーク環境が対応するモデルの API アドレスにアクセスできることを確認してください。そうでない場合、接続テストは失敗します。
5. モデル名はサービスプロバイダが提供するものと完全に一致している必要があります。そうでない場合、Agent の呼び出しで異常が発生します。
