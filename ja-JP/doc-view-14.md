## 1. 概要

行政・勤怠データアシスタントは、勤怠や出張の照会に使用でき、管理スタッフが出張や休暇などのデータを迅速かつ詳細に分析するのを支援します。これにより、データ分析のハードルを下げ、人的リソースを節約します。

## 2. 構築手順

### 2.1 事前準備

管理者として Data Agent プラットフォームにログインし、行政関連データとナレッジベースを追加します。「行政・勤怠データアシスタント」Agent を作成し、Agent 設定画面に入ります。

操作手順については、以下のドキュメントを参照してください：[Agent の作成](https://help.fanruan.com/finereport/doc-view-4.html)

### 2.2 基本設定

1）「管理バックグラウンド > モデル」で追加済みの AI 大規模言語モデルを選択します。ここでは「deepseek-v3.2」モデルを選択します。

2）Agent が要件を正確に認識し、適切な内容を返せるよう、詳細なシステムプロンプトを設定します。サンプルプロンプトは以下の通りです：

```shell
# 役割
あなたはプロの行政・勤怠データ分析アシスタントです。2026年3月の会社の勤怠データ（出張および休暇記録を含む）に基づき、従業員の外出や休暇に関するさまざまな問い合わせに回答する責任があります。
```

### 2.3 データの追加

FineBI から、分析が必要な行政・勤怠関連の分析テーマデータを Agent に追加します。

### 2.4 スキルの追加

「分析テーマデータ照会」スキルを選択して追加し、名前を「行政・勤怠データ照会」に変更します。スキル調整・設定画面で、行政の勤怠・出張データを有効にし、スキルがそのデータに依存できるようにします。

### 2.5 セッション体験の設定

1）適切なウェルカムメッセージを設定します。例：「こんにちは！私はあなたの勤怠・出張照会アシスタントです。出張や休暇データの分析を専門にサポートします」

2）質問と回答の効率を高めるため、初回の推奨質問を設定します。以下の表を参考にしてください：

| 出張照会 | 役員たちの3月第1週の出張状況は？ |
| --- | --- |
| 生産部門の近々のスケジュールは？ | |
| 出張が最も多い部門はどこですか？ | |
| 役員の出張の主な目的地と理由はどこに集中していますか？ | |
| **休暇照会** | 3月に休暇の合計期間が3日を超えたのは誰ですか？またその部門は？ |
| 3月のマーケティング部門の休暇状況 | |
| どの階層のスタッフの休暇が最も多いですか？ | |
| **総合照会** | 3月第1週に不在だった役員は何人ですか？休暇区分の割合は？ |
| 出張者と休暇取得者の割合は？ | |
| 同じ部門で複数人が同時に休暇や出張をしている状況はありますか？ | |

### 2.6 テストと公開

上記の設定が完了したら、右側のプレビューテストエリアで質問と回答のトップページ画面をリアルタイムで確認できます。会話を送信して Agent の回答の正確性をテストします。テストに問題がなければ保存し、「行政・勤怠データアシスタント」をワークベンチおよび独立した URL に公開できます。

## 3. Agent の使用

管理者が Agent を構築して公開した後、一般メンバーユーザーは Data Agent プラットフォームのトップページから Agent を選択して入り、新しいセッションを作成して質問することができます。

Agent との会話およびセッション操作の詳細については、以下のドキュメントを参照してください：[Agent の使用 2.3 Agent との会話](https://help.fanruan.com/finereport/doc-view-5.html#ddfeaa5703c886a8)
