## 1. 概要

### 1.1 機能の概要

「全国市場ポテンシャルインサイトレポート担当」は、管理者が固定レイアウト形式で、全国規模の企業顧客における市場ポテンシャルレポートを生成するための Agent です。レポートには、データ概要、トレンド、市場シェア分析などが含まれます。

### 1.2 利用シーン

以下の分析レポートの生成に対応しています。

- 全国各業界の市場ポテンシャル分析レポート
- 全国特定業界の市場ポテンシャル分析レポート
- 特定都道府県の各業界ポテンシャル分析レポート
- 特定都道府県の特定業界ポテンシャル分析レポート

## 2. 構築手順

### 2.1 事前準備

1. 管理者として Data Agent プラットフォームにログインします。
2. 顧客の市場ポテンシャル分析に関連するデータとナレッジベースを追加します。
3. 「全国市場ポテンシャルインサイトレポート担当」Agent を作成し、Agent の設定ページにアクセスします。

> [!NOTE]
> 事前操作の詳細については、[Agent の作成](./doc-view-4.md) を参照してください。

### 2.2 基本設定

1. 「管理画面」>「モデル」で追加済みの AI 大規模言語モデルを選択します（例：「deepseek-v3.2」モデル）。
2. 詳細なシステムプロンプトを設定し、役割、スキルフロー、呼び出すスキルを明確にします。

プロンプト設定の要件（例）：
- レポート生成に関連する質問を受けた場合は、必ずレポート生成スキルを呼び出して生成すること。
- 既存のレポートに基づく直接出力や、データの捏造は許可しないこと。
- レポート生成の要約時には簡潔なテキストでのみ説明し、添付ファイルやグラフなどを出力しないこと。

### 2.3 データの追加

OrangeBI から、分析レポート生成用の市場ポテンシャル関連のダッシュボードデータを Agent に追加します。

### 2.4 スキルの追加

「ダッシュボードレポート生成」スキルを選択して追加します。固定レイアウトのレポート特性に基づいて、「レポートテンプレートのアップロード」を選択し、AI 解析によりレポートテンプレートを生成します。

#### 2.4.1 スキルセクションのプロンプト調整

実際のレポート要件に合わせて、AI 生成用のプロンプトを調整します。

- **全体プロンプト**：レポート全体のスタイルや形式を規定し、全体に適用されるフィールドのフィルタリングロジックを定義します。例えば、結論分析は自然言語で行うこと、分析内容と重要な元データのみを客観的に表示すること、重要データは太字にすること、および時間、エリア、都道府県、Kline 名称などのパラメータ入力ルールを規定します。
- **セクションタイトル**：`【】` をプレースホルダーとして使用し、エリア、業界、年、都道府県などの変数フィールドを指定します。
- **セクション内容のプロンプト**：出力するグラフ内容や分析の方向性を自然言語で記述します。ここにはデータソース選択ルール、フィールドのフィルタルール、計算ロジック、グラフの形式ルールが含まれます。

#### 2.4.2 セクションデータの構成

プロンプトの調整が完了したら、各セクションで利用可能なデータを設定します。セクションタイトルの左側にあるボタンをクリックし、「Agent 設定ページ」>「データ」で追加済みのダッシュボードコンポーネントを選択します。

- **エリアデータ概要**：エリアの年別データ、エリアの都道府県データ、エリアの複合年間成長率（CAGR）、都道府県の複合年間成長率（CAGR）を選択します。
- **エリア全体データ**：エリアの年別データ、エリアの都道府県データを選択します。
- **業界データ**：Kline 業界データ、業界の複合年間成長率を選択します。
- **業界全体分析**：Kline 業界データ、業界の複合年間成長率を選択します。

また、ダッシュボードの該当する明細表コンポーネントを選択し、第3、第4セクションに表や添付ファイルとして挿入します。

### 2.5 チャット体験の設定

1. 「全国規模の顧客市場ポテンシャルレポート（データ概要、トレンド、市場シェア分析など）を生成します」など、適切なウェルカムメッセージを設定します。
2. 初回のおすすめの質問を設定し、応答の効率を高めます。

### 2.6 テストと公開

設定完了後、右側のプレビューテスト領域で Agent のホーム画面をリアルタイムに確認し、チャットを送信して回答の精度をテストします。問題がなければ保存し、ワークベンチまたは独立した URL に Agent を公開します。

## 3. Agent の使用

管理者が Agent を構築・公開すると、一般ユーザーは Data Agent プラットフォームのホーム画面から当該 Agent を選択して新しいチャットを開始し、質問を行うことができます。Agent とのチャットの詳細は、[Agent とのチャット](./doc-view-5.md#ddfeaa5703c886a8) を参照してください。
