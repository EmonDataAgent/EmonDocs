## 1. 概要と位置づけ

Dora は、エンタープライズレベルのデータエージェント（Data Agent）プラットフォームです。強固なデータセキュリティ基盤と Agent オーケストレーションエンジンを備え、多様なビジネスシーンにおけるデータ分析、レポート作成、アラート通知、データ配信などのプロセスを自動化します。

Dora は、タスクの複雑さに応じて自動的に「思考」（次のアクションを計画）し、「行動」（対応するスキルを呼び出し）します。ビジネスニーズに効率的に対応し、データ取得と分析をより便利でスマートなものにします。

本プラットフォームは、主にデータアナリストやデータレポートを重視する企業の管理者を対象としており、以下の特長があります。

- **データ分析のハードルを低下**：複雑な SQL の記述やレポート設定は不要です。自然言語による質問でデータ詳細を取得できます。
- **分析効率の向上**：専用 Agent の設定をサポートし、構造化された分析レポートを自動生成することで、定型業務を削減します。
- **業務のセルフサービス化を促進**：ユーザは自身で Agent を利用または作成でき、個別の分析ニーズに迅速に対応できます。

## 2. シーン別のアプローチ

財務、オペレーション、営業など、部門ごとに専用の Agent アシスタントを作成することで、データ活用スキルの標準化と再利用を実現します。Agent の作成方法については、[Agentの作成](https://help.fanruan.com/finereport/doc-view-4.html) を参照してください。

### 2.1 データ照会 Agent

データ照会 Agent は、Dora の最も基礎的かつ中核となる機能です。コードの記述や複雑なレポート操作を行わずに、自然言語の対話形式で業務データを直接検索できます。主なメリットは以下の通りです。

- **意図のスマートな解析**：ユーザの質問に含まれる指標、ディメンション、時間範囲などの重要情報を自動的に識別し、実行可能なデータクエリに変換します。
- **正確な結果の返却**：設定済みのデータソースに接続して該当データを迅速に取得し、わかりやすいテキストまたは視覚的フォーマットで回答を提示します。
- **多様なシナリオの検索に対応**：売上高、在庫、勤怠、市場規模など、一般的なビジネス分析シナリオを網羅し、日常的なデータ取得ニーズを満たします。

### 2.2 レポート Agent

レポート Agent は、クエリ結果に基づいて構造化された分析レポートを自動編成・出力し、データ報告や振り返りに対する企業の管理者のニーズに応えます。主なメリットは以下の通りです。

- **データの自動統合**：複数回のクエリ結果や多次元データを集計し、完全なレポート構造を形成します。
- **構造化された出力**：ビジネスロジックに従って、結論、データ詳細、トレンド分析などのモジュールを含むレポートを生成し、可読性を高めます。
- **シーンに応じたカスタマイズ**：経営分析、財務報告、営業の振り返りなど、特定のシナリオに合わせて専用のレポートテンプレートと出力ロジックを設定できます。
