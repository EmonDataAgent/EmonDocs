# AI 固定レポート

## 概要

AI 固定レポートスキルは、あらかじめ設定したレポートのアウトラインと関連データソースに基づき、データを自動的に統合し、ロジックを整理して、標準化されたダッシュボード分析レポートを生成します。このスキルは通常、汎用サマリーレポート、要因分析レポート、比較分析レポートなどの生成に使用されます。また、ローカルのレポートテンプレートをアップロードして、固定レイアウトのレポートを生成することもサポートしています。以下では、汎用サマリーレポートを生成する場合を例に説明します。

## 設定手順

### 1. Agent の作成

設定の第一歩として、Agent を作成します。「[Agent を作成する](?:创建 Agent)」および「[Agent をカプセル化する](?:封装 Agent)」ドキュメントを参照し、経営分析レポート生成用の Agent を作成して、適切なモデルとデータを設定してください。

### 2. スキルの追加とテンプレートの作成

次に、Agent に「ダッシュボードレポート生成」スキルを追加します。スキルを追加するとテンプレート選択画面が表示されます。ここでは以下の3つの方法でレポートテンプレートを作成できます。

1. **空白から新規作成します**。
2. **組み込みテンプレートから新規作成します**。現在、汎用サマリーレポート、要因分析レポート、比較分析レポートの3セットのテンプレートが組み込まれています。
3. **ローカルのレポートテンプレートをアップロードします**。自動的に分析を行い、レポートテンプレートを生成します（現在サポートされているのは docx 形式のファイルのみです）。

### 3. 編集画面の設定

上記いずれかの方法でレポートテンプレートを作成すると、レポート生成スキルの編集画面に移動します。レポート生成スキル名の右側にある編集ボタンをクリックして、スキル名とスキルの説明を変更できます。編集画面全体のレイアウトは、左側の「利用可能なデータエリア」と右側の「コンテンツ編集エリア」の2つのコア領域に分かれています。

#### 3.1 左側領域（利用可能なデータエリア）

左側領域は利用可能なデータエリアであり、レポートスキルが参照できるデータソースを表示し、右側のコンテンツ編集のためのデータ基盤を提供します。このエリアに追加できるデータは、すべて Agent 設定のデータ情報項目に由来します。

利用可能なデータエリアでは、全体データと章ごとのデータに分けて関連付けることができます。
- **全体データ**：このエリアに追加されたダッシュボードデータはドキュメント全体で共通して利用可能であり、レポート全体の任意の章から直接呼び出すことができます。これはレポート全体を貫くコア指標の表示に適しています。
- **章ごとのデータ**：右側の編集エリアの特定の章に対して個別に設定を行い、その章のみが指定されたダッシュボードデータを呼び出せるようにします。

さらに、データフィルタ機能により、ダッシュボード内のフィルタコンポーネントに基づき、自然言語でフィルタ条件を記述して、スキルの分析範囲をより正確に制御できます。

#### 3.2 右側領域（コンテンツ編集エリア）

右側領域はコンテンツ編集エリアであり、プロンプトの編集エリアとして機能します。フォーマットの配置やグラフなどのコンテンツ挿入ツールと連携し、スキルが要件を正確に認識してレポートを精確に生成できるように支援します。

主な機能は以下の通りです。
- **構造化編集とプロンプト設定**：MarkDown 形式でのコンテンツのレイアウトとフォーマット編集をサポートします。管理者は事前にレポート全体や各章のプロンプトを設定し、レポート生成のロジック、スタイル、要件を明確にすることで、システムが要件に沿ったレポートコンテンツを精確に生成するよう導くことができます。
- **視覚化データの挿入**：利用可能なデータエリア内のダッシュボードに含まれるグラフやテーブル、および添付ファイル（ダッシュボード内の明細表を添付ファイルとして埋め込む）の挿入をサポートします。レポート生成後、ユーザは添付ファイルをクリックしてダウンロードでき、データとテキストの深い融合を実現します。
- **グローバルプロンプトの呼び出し**：レポート全体のプロンプトの挿入をサポートします。この設定はレポート全体に適用され、ドキュメント全体の分析フレームワーク、出力基準、文体スタイルを統一・標準化します。

また、「【】」をプレースホルダとして使用し、地域、業界、年などの変数フィールドをマークすることができます。スキルの実行中、ユーザの質問に含まれる該当するディメンション情報が自動的にマッチングされ、コンテンツの動的な適応と生成が完了します。
