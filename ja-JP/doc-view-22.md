# Data Agent のデプロイ操作ガイド

本ドキュメントでは、FineBI プロジェクトに Data Agent をデプロイして有効化する方法について説明します。

## 1. 概要と前提条件

FineBI と Data Agent は順番にデプロイする必要があります。そのため、先に運用プラットフォームを使用して FineBI のデプロイを完了させてください。

- **運用プラットフォームのデプロイ**
  FineBI と Data Agent はいずれも運用プラットフォームに依存しています。
  - **運用プラットフォームが未デプロイの場合:**
    ドキュメントを参照して最新の運用プラットフォームをデプロイしてください。イントラネット環境では、完全版のオフラインインストールパッケージを使用してください。
  - **運用プラットフォームがデプロイ済みの場合:**
    運用プラットフォームが V2.26.0 以上であることを確認してください。最新バージョンへのアップグレードを推奨します。

- **FineBI のデプロイ**
  運用プラットフォームで FineBI をデプロイしてから、Data Agent を追加します。
  - **FineBI が未デプロイの場合:**
    1. FineBI のデプロイ環境（サーバ要件、ネットワーク、マウントディレクトリ）を準備します。
    2. 最新版の FineBI をデプロイします。
  - **FineBI がデプロイ済みの場合:**
    デプロイ方式が「運用プラットフォームデプロイ」であることを確認してください（それ以外はサポートされていません）。
    バージョンは 7.0.7 以上である必要があり、最新バージョンへのアップグレードを推奨します。旧バージョンの場合は、対応する AI イメージについてサポート窓口までお問い合わせください。

## 2. Data Agent の新規デプロイ

FineChatBI をデプロイしたことがない FineBI プロジェクトが対象です。前提条件を満たしていることを確認してください。

### 2.1 Data Agent コンポーネントサーバの準備

Data Agent は多くのリソースを消費するため、専用のサーバを用意することを推奨します。

- **推奨要件:** CPU 16 コア、空きメモリ 64GB、空きディスク 100GB。AI コンポーネント専用サーバ。
- **最低要件:** CPU 8 コア、空きメモリ 16GB、空きディスク 80GB。AI コンポーネントと FineBI を共有。BI デプロイ後に空きリソースがあることを確認してから作業してください。

**基本要件:**
- **時刻とタイムゾーンの同期:** Data Agent サーバと他のサーバ間の時刻のずれは 5 秒以内で、タイムゾーンが完全に一致している必要があります。
- **イントラネット通信:** サーバ間のイントラネット通信（レイテンシ 1ms 未満）または指定ポートへのアクセスを許可してください。
- **環境の制限:** 仮想マシンでの運用は推奨されません。また、Data Agent コンポーネントは Kubernetes（K8S）環境でのデプロイをサポートしていません。

**OS 要件:**
- **タイプとアーキテクチャ:** Linux（X86_64 または ARM）。
- **カーネル:** 3.10 以上。
- **推奨 OS:** Ubuntu 22。サポート対象は Ubuntu 18.04.4 以上（20.04 は非サポート）、CentOS 7.3~7.9、RedHat 7.6 以上、Rocky Linux 8.8~9.4 です。Ubuntu を使用する場合、デフォルトの root ユーザが管理者権限を持たない場合があるため注意してください。

**ハードウェアの詳細:**
- **CPU:** Intel Xeon Gold 6338 などの高性能プロセッサを推奨（クロック数 2.5GHz 以上）。
- **ディスク性能:** SSD が必須です。
- **マウントディレクトリ:** 再起動時の自動マウントを設定し、共有パスは使用しないでください。`/`、`/usr`、`/root`、`/usr/local` を直接マウントすることは禁止されています。
- **コマンドと権限:** `tar` および `sed` コマンドが必要です。ssh 接続（パスワードに英字の一重引用符を含まないこと）および sudo 権限が必要です。

**ポートとネットワーク:**
デフォルトのコンテナマッピングポートが使用されていないことを確認してください（FineAI: 7666、FineChatBI 意味解析スモールモデル: 8666、FineAI Redis: 6679）。
- **FineAI (fine-ai):** BI プロジェクトのイントラネットゲートウェイおよび各 bi-web からアクセス可能。
- **意味解析スモールモデル (fine-chat-bi-parser):** BI プロジェクトの各 bi-web からアクセス可能。
- **FineAI Redis (fine-ai-redis):** 意味解析モデルおよび FineAI からアクセス可能。

### 2.2 Data Agent イメージとプラグインの準備

Data Agent のイメージはクラウドから直接取得できないため、手動でプッシュする必要があります。

1. FineAI コンポーネントイメージと FineChatBI 意味解析スモールモデルイメージをダウンロードします（ARM 用はサポート窓口にお問い合わせください）。
2. 運用プラットフォームの「運用プラットフォーム管理 > 運用コンポーネント」でデプロイ情報をエクスポートします。サーバ上でエクスポート先 `logs` フォルダと同じ階層にある `resources` フォルダにイメージファイルをアップロードします。
3. 運用プラットフォームの「メンテナンスセンター > イメージ管理」で「イメージをロード」をクリックします。
4. デプロイ一覧から手動でコンポーネントのイメージバージョンを変更し、イメージ管理と一致させます。
5. リポジトリに v20.3.0-6.2.17 以上の Redis イメージが存在することを確認します。

### 2.3 Data Agent コンポーネントのデプロイ

1. 運用プラットフォームにログインし、該当の FineBI プロジェクトで「メンテナンス > コンポーネント管理」を開きます。
2. 「コンポーネントの追加」をクリックし、「ビジネスサービス > AI」を選択します。
3. （任意）新規サーバの場合は「ノード追加」をクリックし、イントラネット IP、ポート（デフォルト 22）、sudo 権限ユーザ名、マウントパス（デフォルト `~/data`）を入力します。
4. 対象ノードを選択します（要件を満たさないノードはグレーアウトされます）。
5. ポート設定を調整し、**必ず FineAI Redis コンポーネントのパスワードを変更**してください。
6. 「デプロイ開始」をクリックします。

### 2.4 設定とライセンスの取得

1. Data Agent プラグインをダウンロードします。
2. FineBI のシステム管理からローカルインストールでプラグインをインストールします。
3. 営業またはサポート窓口に連絡して Data Agent ライセンスを取得し、インストールします。
4. 右上に「Data Agent」ボタンが表示されれば設定完了です。

## 3. Data Agent のアップグレードデプロイ

FineChatBI を**デプロイしたことがある** FineBI プロジェクトが対象です。互換性についてはお客様自身でご確認いただくか、新規プロジェクトでの構築を強く推奨します。

1. FineBI のシステム管理にログインし、FineChatBI プラグインをアンインストールします。
2. [2.2 Data Agent イメージとプラグインの準備](#22-data-agent-イメージとプラグインの準備) を参照し、最新のイメージをプッシュしてバージョン番号を修正します。
3. 運用プラットフォームの「コンポーネント管理」で、既存の FineChatBI コンポーネントを Data Agent にアップグレードします。
4. FineBI に最新の Data Agent プラグインをローカルインストールします。
5. Data Agent ライセンスを取得・インストールし、右上にボタンが表示されることを確認します。

## 4. メンテナンスとアップグレード

### 4.1 Data Agent のアップグレード
1. FineBI プロジェクトを最新版にアップグレードします。
2. 最新の AI イメージパッケージを運用プラットフォームにプッシュします。
3. 運用プラットフォームの「メンテナンス > コンポーネント管理」で対象の AI コンポーネントの「更新」をクリックします。
4. 完了後、FineBI の Data Agent プラグインも最新にアップグレードします。

### 4.2 ElasticSearch コンポーネントのアップグレード
1. ElasticSearch コンポーネントを v20.4.5-8.17.3 以上にアップグレードし、running 状態であることを確認します。
2. 開発者モードで ElasticSearch の環境変数を編集し、`INSTALL_FINE_PLUGIN` を `yes` に設定します。

## 5. 接続テスト

本番環境で Data Agent を使用する前に、管理者による接続テストが必要です。

1. **プラットフォーム接続テスト:** 
   「Data Agent 管理コンソール > オープンインテグレーション > その他」に移動し、バックグラウンドアドレスに FineBI のアドレスを追加して「接続テスト」をクリックします。
2. **モデル接続テスト:** 
   「Data Agent 管理コンソール > モデル」で、追加した対象モデルの接続テストを行い、利用可能状態であることを確認します。
