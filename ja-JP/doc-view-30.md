## 機能の概要

IM ユーザマッピング機能は、サードパーティ製 IM プラットフォームのユーザと Data Agent プラットフォームのユーザを紐付けるための機能です。このマッピングを設定することで、定期実行タスクの通知設定において、IM 側の受信者を正確に識別できるようになります。

この機能により、タスクの通知対象を IM ツールのユーザと紐付け、メッセージを目的のユーザやグループに確実に配信できます。企業の多様なユーザ管理手法に柔軟に対応し、プラットフォームのユーザと IM ユーザの ID 統合を実現します。また、個別追加と一括アップロードの双方をサポートしており、様々な規模の企業のニーズに応え、管理効率を向上させます。

## 設定手順

### 設定画面へのアクセス

管理者権限で「管理画面」>「ユーザ管理」>「IM ユーザマッピング」タブにアクセスします。画面には設定可能な IM プラットフォームのリストが表示されます。対象プラットフォーム（企業WeChat など）の右側にある「編集」ボタンをクリックすると、設定画面に入ります。

> **ℹ お知らせ：** 現在は企業WeChatのマッピングのみサポートしています。飛書（Feishu）および釘釘（DingTalk）のサポートは今後のバージョンで追加される予定です。

### アプリケーションの連携

ユーザマッピングを行う前に、企業WeChat の管理者が企業WeChat 管理画面にログインし、アプリケーション連携を完了させる必要があります。詳細はドキュメント『[企業微信機器人-應用對接](https://help.fanruan.com/finereport/doc-view-52.html)』をご参照ください。

### ユーザマッチング方式の選択

設定画面に入ると、2 つのユーザマッチング方式がサポートされており、実際の運用シナリオに応じて選択できます。

*   **ユーザ名/ID マッチング**：2 つのプラットフォーム間でユーザ名またはユーザ ID が同一である、あるいは明確な対応関係が存在する場合に使用します。
*   **カスタムマッチング**：2 つのプラットフォーム間でユーザ名や ID が異なり、手動でマッピング関係を構築する必要がある場合に使用します。

#### 方式 1：ユーザ名/ID マッチング

「用户名/ID 匹配」（ユーザ名/ID マッチング）オプションを選択すると、システムは自動的にサードパーティ製 IM プラットフォームと Data Agent プラットフォームのユーザ名や ID をマッチングしようと試みます。

マッチングに成功したユーザは Data Agent プラットフォームに自動同期されるため、手動での設定は不要です。設定後に「保存」をクリックすると、直ちにルールが適用されます。

#### 方式 2：カスタムマッチング

「自定义匹配」（カスタムマッチング）オプションを選択すると、下部の「ユーザマッピング」エリアでマッピング表をアップロードし、一括設定を行うことができます。手順は以下の通りです。

1.  インポート用テンプレートをダウンロードし、そのフォーマットに従ってマッピング表ファイルを作成します（現在は `.xls` および `.xlsx` 形式のみサポート）。
2.  ファイルをアップロードするとシステムが自動解析を行い、画面上に企業WeChat のユーザ名と Data Agent のユーザ名が同期して表示されます。
3.  マッチング後、必要に応じて企業WeChat ユーザに対応する Data Agent ユーザ名を手動で変更できます。

## 注意事項

*   企業WeChat のユーザデータを連携させるには、あらかじめ企業WeChat の管理者がバックグラウンドからユーザ ID をエクスポートしておく必要があります。
*   「ユーザ名/ID マッチング」を使用する場合は、IM プラットフォームと Data Agent プラットフォームのユーザ名や ID が完全に一致している必要があります。一致しない場合、自動マッチングは行われません。
*   一括アップロード用のマッピング表は、必ずテンプレートのフォーマットに従って記入してください。列名や形式に不備があると解析エラーになります。
