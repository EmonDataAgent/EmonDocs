# FineReportレポート検索スキル

## 機能の概要

FineReportプラットフォームと連携することで、レポートの検索、プレビュー、データ分析、およびパラメータ調整をサポートします。手動でレポートを探す必要はなく、セッション内で直接質問するだけで、FRプロジェクト内のレポートデータを呼び出すことができます。

- **レポート検索とプレビュー**：自然言語による説明を通じて、目的のレポートをすばやく特定し、コンテンツをプレビューします。
- **レポートデータ分析**：レポート内のデータに対して、指標の検索、トレンド分析、および比較集計を行います。

Agentの設定と公開が完了すると、セッション内で接続済みのFRプロジェクトのレポートデータを直接呼び出し、検索、プレビュー、および分析を実行できます。FineReportプラットフォームに切り替えて手動で操作する必要はありません。

## FineReport環境の準備

「FRレポート検索」スキルを設定する前に、対象のFRプロジェクトで「FR検索プラグイン」のインストールとテンプレート検索の設定を完了し、FRプロジェクトがAgentから呼び出せる状態にしておく必要があります。

1. **プラグインのインストール**：FR検索プラグインをダウンロードしてインストールします。ダウンロードしたZIPファイルは解凍せず、そのままインストールしてください。インストールが成功すると、インストール完了のダイアログが表示されるので、「OK」をクリックします。
2. **モデルの設定**：プラグインのインストール後、「管理システム」>「テンプレート検索」>「モデル設定」をクリックして、大規模言語モデルとベクトルモデルを設定します。設定が完了したら、「テストして接続」を実行し、モデルが使用可能であることを確認します。
3. **テンプレートの設定**：「管理システム」>「テンプレート検索」>「テンプレート設定」をクリックし、メタデータを生成するためのテンプレートを設定します。

## スキルの設定

1. Data Agentプラットフォーム上で、FRレポートの検索と分析に使用するAgentを準備します。
2. 「Agent設定ページ」>「スキル」にて、「FRレポート検索」スキルを選択して追加します。
3. スキルが接続するFRプロジェクトを設定し、現在のスキルがアクセスできるFRプロジェクトの範囲を指定します。
4. 接続方式を設定します。既存の接続から選択するか、新規接続を作成できます。
   - **既存の接続**：Data Agentプラットフォーム内で、他のAgentで作成済みのFRプロジェクト接続は自動的に記録されます。これらを再利用できるため、設定を繰り返す必要はありません。
   - **新規接続**：再利用可能な既存の接続がない場合は、「新規接続」をクリックして新しいFRプロジェクト接続を作成します。プロジェクトを識別するための任意の「接続名」と、「FRサーバアドレス」（プラグインのインストールと設定が完了しているFRプロジェクトの環境アドレス）を入力します。
