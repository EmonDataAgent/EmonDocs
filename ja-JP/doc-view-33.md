# Dora データ検索と分析系スキルの比較

無効な検索を回避し、実行速度を向上させながらトークン消費を削減してユーザ体験を最適化するために、**データソースごと**に各 Agent に**単一の専用**データ検索・分析スキルを割り当てることを推奨します。

データ検索と分析には、次の4つのタイプのスキルが含まれます。

| スキル名 | 概要 | 代表的なシナリオ |
| --- | --- | --- |
| ダッシュボード検索 | バインド済みのダッシュボード範囲内で資産データを検索し、指標のクエリ、トレンド分析、比較集計などの業務上の質問に回答します。 | - **ダッシュボードデータ検索**：ダッシュボードのグラフと指標に基づき、直接質問して数値、ランキング、前年/前月比データを取得します。<br>- **ダッシュボード分析**：ダッシュボードデータに基づき、重要指標とトレンドの変化を自動的に集計し、構造化された分析を出力します。 |
| データ分析 | Excel/CSV 形式のデータソースに対するクエリ、集計、およびエクスポート操作をサポートします。 | データソースが Excel/CSV 形式のローカルファイルである場合、ファイルをアップロードして直接データの検索と分析を行えます。 |
| FR レポート検索 | FineReport プラットフォームと連携し、手動でレポートを探すことなく、レポートの検索、プレビュー、データ分析、およびパラメータ調整をサポートします。 | - **レポートの検索とプレビュー**：自然言語での記述を通じて、目的のレポートを素早く特定し、内容をプレビューします。<br>- **レポートデータ分析**：レポート内のデータに対して、指標クエリ、トレンド分析、比較集計を行います。 |
| 分析テーマデータ検索 | 自然言語を介したデータ検索をサポートし、構造化されたデータ結果を返します。 | 追加された FineBI 分析テーマデータソースまたは Excel データソースに対して、自然言語によるデータ検索を行います。 |

## 設定手順

### 1. Agent の準備

Data Agent プラットフォームで、データソースに対するデータ検索・分析操作を行うための Agent を準備します。

### 2. スキルの追加

「Agent 設定ページ > スキル」にて、使用シナリオの要件に応じて、「データ検索と分析」カテゴリから適切なスキルを追加します。

### 3. スキルの設定

各種スキルの要件に合わせて個別の設定を行います。

1. ダッシュボード検索スキルの場合、利用可能なダッシュボードを設定する必要があります。
2. FR レポート検索スキルの場合、FR プロジェクト環境の設定などを行う必要があります。
3. 分析テーマデータ検索スキルの場合、事前にデータソースを追加し、検索範囲を制御するために、スキルで検索可能な分析テーマデータを選択する必要があります。
