## 1. 概要

### 1.1 機能の概要

ダッシュボード検索スキルを使用すると、バインドされたダッシュボードの範囲内でアセットデータを検索し、指標の照会、トレンド分析、比較集計などのビジネス上の質問に回答することができます。

### 1.2 利用シーン

- **ダッシュボードデータの照会**: バインドされたダッシュボード内のグラフや指標に対して直接質問し、数値、ランキング、前年同期比および前月比などのデータを取得します。
- **レポート作成**: ダッシュボードのデータに基づき、主要な指標とトレンドの変化を自動的に集計し、構造化された分析レポートを出力します。

### 1.3 デモンストレーション

Agent を OrangeBI プラットフォームに公開した場合を例として、ダッシュボード検索の効果を確認できます。

## 2. 設定手順

### 2.1 事前準備

1. **ElasticSearch コンポーネントのバージョン確認**: ElasticSearch コンポーネントを v20.4.5-8.17.3 以降のバージョンにアップグレードし、ElasticSearch コンポーネントが running 状態であることを確認してください。
2. **ElasticSearch コンポーネントの環境変数のカスタマイズ**: 開発者モードから ElasticSearch コンポーネントの環境変数をカスタマイズし、`INSTALL_FINE_PLUGIN` の値を `yes` に変更してください。

### 2.2 Agent の準備

プラットフォーム上でダッシュボードデータ分析用の Agent を作成し、ダッシュボードデータの追加を完了します。

### 2.3 スキルの追加

「Agent 設定ページ > スキル」にて、「ダッシュボード検索」スキルを選択して追加します。

### 2.4 スキルの設定

スキルが検索できるダッシュボードの範囲を選択し、データの境界を固定します。範囲を限定することで、以下の 2 つの問題を回避できます。
- 範囲が狭すぎる場合: 検索結果としてデータが返されない問題。
- 範囲が広すぎる場合: 無関係なデータが結果に干渉し、トークン消費量が増加する問題。

### 2.5 Agent の公開

以上の設定が完了したら、エンドユーザーが利用できるように異なる公開方法で Agent を公開します。Agent は以下の 3 つのチャネルへの公開をサポートしており、各チャネルの利用方法と適用シーンは異なります。

| 公開方法 | ユーザーの利用方法 | 適用シーン |
| --- | --- | --- |
| **ワークベンチ** | Data Agent プラットフォーム上で、対話形式でバインドされたダッシュボードのデータに対して質問・分析を行います。 | Data Agent プラットフォームの内部ユーザーによる日常的なデータ照会と分析。 |
| **独立 URL** | 独立したリンクを通じて Agent にアクセスし、対話形式で質問・分析を行います。 | Data Agent プラットフォームへのログイン不要で、外部の担当者に Agent を共有する必要がある場合。 |
| **OrangeBI プラットフォーム** | OrangeBI の「ディレクトリ」にて、Agent の表示範囲内にあるダッシュボードページからサイドバー経由で Agent を呼び出し、直接質問・分析を行います。 | OrangeBI ユーザーがダッシュボードを閲覧中に、ページを切り替えることなく即座に質問したい場合。 |
