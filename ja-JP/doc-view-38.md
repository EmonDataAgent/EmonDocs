# IM ツールの連携

## 概要と利用シナリオ

IM ツールの連携は、Agent が複数のプラットフォームを介してユーザにアプローチするための機能モジュールです。この機能により、インテリジェントエージェントをサードパーティのインスタントメッセージングツールのボットと紐付け、Agent がサードパーティプラットフォームを介してユーザと対話できるようになります。
現在、WeChat Work（企業微信）ボットとの連携のみをサポートしています。DingTalk（釘釘）および Lark（飛書）との連携は今後サポートする予定です。

よくある利用シナリオは以下の通りです。
- **個人チャット**：ユーザが WeChat Work で Dora ボットと個別のチャットを開始します。個人の日常的なデータ検索に適しています。
- **グループチャット**：ユーザがグループチャットで Dora ボットをメンション（@）して、データ検索やレポート作成を開始します。チームでの共同作業に適しています。
- **メッセージカードのデザイン**：IM ボットの返信には、重要な数値やシンプルなチャート（棒グラフや折れ線グラフ）を含むリッチテキストのメッセージカードが使用されます。

グループチャットのシナリオを例に挙げると、@Dora ボット宛てに質問を送信すると、ボットがリアルタイムで回答します。
マルチターンの対話がサポートされており、コンテキストは常に保持されます。ユーザは続けて質問することができ、ボットは以前の会話の文脈に基づいて一貫した回答を提供します。

## 設定手順

Agent で IM ツールを設定する前に、システム管理者として「管理コンソール > ユーザ管理 > IM ユーザマッピング」にアクセスし、プラットフォームと IM ツール間のユーザマッピングを完了する必要があります。
操作の詳細については、ドキュメント「[IM ユーザマッピング](https://help.fanruan.com/finereport/doc-view-30.html)」を参照してください。

マッピングが完了したら、以下の手順に従って設定を行います。

1. 最新バージョンの WeChat Work で「連絡先 > スマートボット」にアクセスし、Dora プラットフォーム内の Agent に接続して対話分析を行うためのボットを作成します。
2. ダイアログで「手動作成」を選択して、ボット作成画面に入ります。
3. ボット作成画面を一番下までスクロールし、「API モード作成」に切り替えます。
4. ボットの用途に応じて、識別しやすいボット名をカスタマイズします。
5. 利用可能なメンバーに、WeChat Work の連絡先から、このボットと対話できるメンバーまたは部署を追加します。
6. API 設定で長時間の接続（ロングコネクション）方式を選択し、Bot ID をコピーして Secret を取得します。これらは Dora プラットフォームの Agent に設定するために使用します。
7. 「Agent 設定画面 > IM ツールの連携」にアクセスし、モジュール右上の「+」ボタンをクリックして、「IM ツールの連携」ダイアログを開きます。
8. 「WeChat Work ボット」を選択して、WeChat Work ボットの設定画面に入ります。
9. 前の手順で取得した Bot ID と Secret の情報を Agent に設定します。Bot ID と Bot Secret は、WeChat Work ボットの設定情報と完全に一致している必要があります。一致しない場合、連携に失敗します。
10. 設定が完了したら、WeChat Work でボットにテストメッセージを送信し、対話が正常に機能するかどうかを確認します。
11. 設定を変更する場合は、「IM ツールの連携」リストから該当するボットを見つけ、「設定」をクリックして再度編集します。
