## 概要

監査ログは、管理者向けに全プラットフォームの全モジュールに対する操作の履歴を提供します。プラットフォーム内の Agent、データ、モデル、オープン連携などのモジュールに対するアクションを追跡および監査し、操作のトレーサビリティとリスク管理を実現します。

主な利用シーンは以下のとおりです。
- **Agent のライフサイクル監視**：Agent の作成、更新、削除、リリース、リリース取消などの操作を追跡します。
- **データ資産の変更の特定**：データディレクトリ、分析テーマ、ダッシュボード、データソースの作成、更新、削除を記録し、データの変更を追跡します。
- **モデル設定操作の監視**：LLM モデル設定の作成、更新、削除、テスト操作を監視し、モデルサービスの安定性を確保します。
- **オープン連携の変更追跡**：外部 MCP、連携キー、バックエンドアドレスの作成、更新、削除操作を記録し、設定リスクを防ぎます。
- **異常な操作のトラブルシューティング**：操作ログを通じて異常な操作を迅速に特定し、変更に関する問題をトラブルシューティングし、プラットフォームの安全で安定した運用を保証します。

## ログの表示とフィルタ

監査ログリストには、すべての操作履歴が新しい順に表示されます。操作時間やユーザなどのフィールドでフィルタしてログを表示できます。

監査ログリストには以下のフィールドが含まれます。

| フィールド | 説明 |
| --- | --- |
| 操作時間 | 操作が発生した正確な時刻を記録します。時間範囲によるフィルタをサポートします。 |
| ユーザ | 操作を実行したユーザアカウントを記録します。ユーザ名によるフィルタをサポートします。 |
| モジュール | 操作が属するプラットフォームのモジュール（Agent、データ、モデル、オープン連携など）を記録します。 |
| オブジェクトタイプ | モジュール内の具体的な操作対象のタイプ（Agent、ダッシュボード、データソース、LLM 設定など）を記録します。 |
| オブジェクト名 | 操作対象の具体的な名前（Agent 名、ダッシュボード名など）を記録します。 |
| 操作 | 具体的な操作アクション（作成、更新、削除、リリース、リリース取消、テストなど）を記録します。 |
| 結果 | 操作の実行結果（成功 / 失敗）を記録し、異常な操作の迅速な特定を可能にします。 |
