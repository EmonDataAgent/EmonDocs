## 1. 概要

「権限管理」画面では、指定ユーザに対して Agent フロントエンドの利用権限と、管理バックエンドの操作権限を設定し、きめ細かな権限制御を実現します。

## 2. 設定手順

### 2.1 設定の入り口

特権管理者として「管理バックエンド>権限管理」にアクセスすると、プラットフォーム上の全ユーザに対する権限の割り当てが可能です。

### 2.2 ユーザの選択

権限管理画面の左側にはユーザリストが表示されます。任意のユーザ名をクリックすると、右側のパネルが当該ユーザの権限設定内容に更新されます。

### 2.3 プラットフォーム権限の割り当て

ユーザに対して、プラットフォームにおける「Agent フロントエンド利用」および「管理バックエンド」の2種類の権限を割り当てることができます。

- Agent フロントエンド利用：該当ユーザが利用可能かどうかを制御します。
- 管理バックエンド：開発ユーザ向けにバックエンド各モジュールの操作権限を設定します。

管理バックエンドの各モジュールにおける権限の範囲は以下の通りです。

- **Agent モジュール**
  - 個人開発権限：自身の Agent の作成、編集、削除が可能です。
  - 管理権限：Agent の公開が可能です。
- **モデルモジュール**
  - 個人開発権限：個人利用を目的としたモデルの追加・削除が可能です。
  - 管理権限：パブリックモデルの追加・削除が可能です。
- **Agent監管モジュール**
  - 個人開発権限：自身が管理権限を持つ Agent の監管データを閲覧できます。
  - 管理権限：設定なし
- **オープン統合モジュール**
  - 個人開発権限：オープン統合画面の閲覧と利用が可能です。
  - 管理権限：設定なし

注意事項：
- ユーザの閲覧時には、管理バックエンドの権限設定はサポートされません。
- 個人開発権限は、ユーザに開発関連の操作を許可します。
- パブリック管理権限は、ユーザにグローバル共有リソースの管理を許可します。

### 2.4 データ権限に関する説明

プラットフォームのデータ権限は FineBI プラットフォームと一致します。ユーザが Agent 内でアクセスできるデータの範囲は、FineBI プラットフォームにおけるデータディレクトリの権限に依存します。

- 開発者は「管理バックエンド>データ」において、自身が FineBI プラットフォーム上で権限を持つデータリソースのみを追加できます。
- FineBI プラットフォームにおいて特定のデータソースに対する権限を持たないユーザは、Agent 内で該当データをクエリできません。
- 上記のデータ権限の制限は、FineBI プラットフォームのデータソースのみに適用されます。

以下のデータはデータ権限の制限を受けず、ユーザに FineBI プラットフォームの権限がなくても Agent 内で正常にクエリできます。
1. アップロードされたローカルの Excel データソース。
2. Excel データを使用する分析テーマ。
