## 1. 概要

スケジュールタスク監視ページでは、Agent におけるスケジュールタスクのプッシュチャネル、タスクソース、実行履歴、および起動ステータスなどの情報を一元的に確認できます。タスクリストから実行履歴およびセッション履歴までドリルダウンすることが可能です。

## 2. スケジュールタスクリスト

### 2.1 スケジュールタスク情報

設定済みのスケジュールタスクを持つ Agent の情報確認と編集管理をサポートします。リストに表示される項目と機能は以下の通りです：

| 項目 | 説明 |
| --- | --- |
| タスクプロンプト | Agent に送信される実際のコマンド内容 |
| 実行頻度 | タスクの実行サイクル |
| プッシュチャネル | タスク結果のプッシュ方法 |
| タスクソース | タスクの作成方法：「私が追加したもの」、「Agent 内で設定」 |
| 到達ユーザー | タスク結果を受け取るユーザー |
| 実行履歴 | 「表示」をクリックすると、該当タスクの実行履歴へ遷移します |
| 操作 | - タスクの開始/停止<br>- タスク内容の編集<br>- タスクの削除 |

### 2.2 実行履歴の表示

1. スケジュールタスクリストで、該当するタスク実行履歴の表示ボタンをクリックすると、タスク専用の実行履歴詳細ページにアクセスできます。
2. 詳細ページの上部には、タスク名と作成元が表示されます。到達ユーザーやプッシュチャネルを絞り込み条件として使用し、過去の実行データを迅速に検索できます。

### 2.3 セッション履歴の表示

スケジュールタスクの実行履歴ページにアクセスした後、個別の実行履歴の表示ボタンをクリックし、ポップアップウィンドウで対応する到達ユーザーを選択します。これにより、セッション履歴セクションに自動的に遷移し、該当するセッションの詳細が正確に特定されます。
