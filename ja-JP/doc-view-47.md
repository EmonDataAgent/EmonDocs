# Emon大規模モデルトラブルシューティングガイド

本記事では、Emon の大規模モデルにおける接続およびリクエストエラーの一般的な解決方法について説明します。

## 1. 事前確認

具体的な問題の調査を始める前に、以下の点をご確認ください。

- **大規模モデル仕様の確認**: 大規模モデルおよびそのパラメータ、同時実行能力が[推奨大規模モデル](./doc-view-26.md)の要件を満たしていることを確認してください。
- **接続テストの完了確認**: [接続テスト](./doc-view-22.md#6efaa47240586242)が完了していることを確認してください。これには以下が含まれます。
  - FineAIプラグインと OrangeBI プラットフォーム間の通信テスト
  - 大規模モデルの接続テスト

## 2. よくある質問

### 2.1 接続テストに失敗する

- **FineAIプラグインと OrangeBI プラットフォーム間の通信テストが失敗した場合**
  `F12` キーを押してブラウザの開発者ツールを開き、`test` リクエストのレスポンスにある `error_message` フィールドを確認します。このフィールドから、BIがFineAIに接続できないのか、FineAIがBIに接続できないのかを判断できます。
- **大規模モデルの接続テストが失敗した場合**
  同様に `F12` を使用してリクエストのレスポンスにある `error_message` を確認し、具体的な原因を特定します。

### 2.2 Emon が正常に応答しない、リクエストがタイムアウトする、または応答がない

**原因**: ネットワーク通信の問題。
**調査手順**:
1. FineAIノードが正常に動作しているか確認します。FineAIは大規模モデルに直接接続できますが、BI-WebはFineAIと双方向通信を行う必要があります。
2. 接続テストをクリックして通信状況を検証します。
3. 接続テストが失敗した場合は、`F12` を通じて `error_message` を確認し、接続が切断されている箇所を判断します。

### 2.3 1回目のリクエストでエラーが発生し、2回目のリクエストは正常に処理される

**原因**: Emon は `tool_call` に依存していますが、現在使用している大規模モデルがこれをサポートしていません。
**調査手順**:
以下の2つの curl コマンドを使用して比較テストを行います。
- 1つ目のコマンド（`tool_call` を含む）: 大規模モデルがサポートしていない場合はエラーになります。
- 2つ目のコマンド（`tool_call` を含まない）: 正常に応答します。
1つ目でエラーが発生し2つ目で正常に応答する場合、使用中のモデルが `tool_call` をサポートしていないため、モデルを変更する必要があります。

### 2.4 リクエストが 422 ステータスコードを返す

**原因**: デプロイされた大規模モデルが OpenAI インターフェースプロトコルの仕様に準拠していない可能性があります。
**調査手順**: インターフェースのログを提供し、開発部門に調査を依頼してください。

### 2.5 リクエストの system content 関連フィールドでエラーが発生する

**原因**: 一部の大規模モデルは `system content` として string 型のみをサポートしており、他のフォーマットをサポートしていません。
**調査手順**: 現在使用している大規模モデルに `system content` フォーマットの制限があるか確認し、制限がある場合はリクエストフォーマットを調整してください。

### 2.6 Azure OpenAI 使用時に接続テストが失敗する

**原因**: Azureは現在、`responses API` フォーマットの endpoint をサポートしていません。
**調査手順**: endpoint を `base URL` フォーマットに変更することで接続できるようになります。

### 2.7 ai-server-error エラーが返される

**原因**: 大規模モデルのコンテキスト長が128k未満です。
**調査手順**: モデルのコンテキスト長が128Kの最低要件を満たしているか確認してください。

### 2.8 Azureモデルの応答内容が異常、または途切れる

**原因**: Azureモデルに組み込まれているコンテンツ安全拒否メカニズムにより、特定のキーワードがトリガーされると応答が中断されます。
**調査手順**: 質問内容を変更し、拒否キーワードをトリガーしないようにしてください。

### 2.9 モデルの呼び出しに失敗し、アクセスできないと表示される

**原因**: モデルサービスへの負荷が高すぎて、一時的に応答できない状態です。
**調査手順**: しばらくしてから再度お試しください。推奨大規模モデルの同時実行とパフォーマンスの参考情報を確認し、モデルの負荷状況を評価してください。

### 2.10 モデルの呼び出しで残高不足に関連するエラーが返される

**原因**: モデルのアカウント残高が不足しています。
**調査手順**: チャージ後に再度ご使用ください。
