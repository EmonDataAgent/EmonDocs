## 1. 概要

Data Agent ワークスペースは、Agent ベースのインテリジェントなチャット機能を提供します。ユーザーは設定済みの Agent を直接選択し、自然言語での対話を通じて、データの照会、ナレッジの検索、分析レポートの作成などのタスクを迅速に完了できます。

主な利用シーンは以下の通りです：
- **日常的なデータ照会**：業務担当者が直接 Agent に質問し、売上、在庫、注文などの業務データを迅速に取得します。
- **複数回のチャットによる分析**：同じ対話セッション内で連続して質問を深掘りし、業務上の課題を段階的に分析します。
- **過去のチャットの振り返り**：左側の履歴パネルから、以前の分析セッションを素早く見つけて再開できます。

チェーン店分析の例として、「チェーン店分析」Agent を選択し、「2025年の各省の売上高の前年比は？」と質問すると、Agent は自動的に質問を解析し、データソースからデータを取得して結果を返します。「その中で華東地域のトップ3の省はどこですか？」のように連続して質問し、分析の次元をさらに細分化することも可能です。

## 2. 設定手順とワークスペースの紹介

Data Agent にログインすると、ワークスペースには公開済みのすべての Agent がカード形式で表示されます。上部の検索ボックスを使用して、目的の Agent を素早く見つけることができます。目的の Agent カードをクリックすると、その Agent のチャット画面に移動します。

新しい分析タスクを開始する場合は、左側の「新しいチャット」ボタンをクリックしてください。これにより、現在の対話コンテキストがクリアされ、新しいセッションが開始されます。「新しいチャット」をクリックするたびに独立したコンテキストが開始され、Agent は前回の対話内容を記憶しません。そのため、連続した質問は同じ対話セッション内で行ってください。

過去のチャット履歴は左側のパネルに表示されます。履歴をクリックすると、その対話セッションに入り、未完了の分析を続けることができます。

## 3. Agentとの対話

画面中央の入力ボックスに質問を入力し、送信ボタンをクリック（または Enter キーを押下）して質問を送信します。Agent は自動的に質問の意図を解析し、対応するスキルを呼び出して、チャット領域に結果を返します。さらに分析が必要な場合は、同じ対話セッション内で質問を続けることができます。

また、対話の修正は主に以下の2つのビジネスシーンに適用されます：
- **Agent の回答にずれがある場合**：Agent の出力内容に誤りがある、またはユーザーの期待を満たしていない場合、ユーザーは直接異議を唱えたり、修正を要求したり、指示の戦略を調整したりできます。Agent は自動的に振り返りを行い、適切な結果を再生成します。
- **ユーザーの質問に誤りがある場合**：ユーザーが入力した質問に誤りがあり、Agent が既に応答の生成プロセスに入っている場合、ユーザーはチャットボックスで簡潔で正しい質問を再送信できます。Agent は元のタスクを自動的に中断し、最新の正しい質問に基づいて応答を再生成します。

## 4. セッション管理とワークスペースの操作

Agent が内容を出力した後、ユーザーは下部の「いいね」や「よくないね」のアイコンをクリックして、リアルタイムでチャットの品質を評価できます。Agent に関連するデータ、ナレッジ、スキルなどに変更があった場合、またはネットワークの問題で内容が正常に出力されなかった場合は、「再生成」をクリックできます。

また、複数のチャット内容を選択し、リンクを通じてプラットフォーム内の他のユーザーに共有することも可能です。チャットの共有は「スナップショット」形式で行われ、最終的な出力結果のみが共有され、Agent の思考や分析プロセスは共有されません。

レポート生成系の Agent がタスクを完了すると、チャットボックスの右上に「ワークスペース」への入り口が自動的に表示されます。ここには、Agent のタスクプロセスで生成されたファイルや最終的なレポートファイルが一元的に保存されます。

ワークスペースでは以下の操作がサポートされています：
- **出力ファイルの切り替え**：Markdown レポート、HTML レポート、PPT レポートに対応しています。
- **表示モードの切り替え**：ソースコードとビジュアル表示の切り替えに対応しています（Markdown、HTML、PPT レポートすべてに対応）。
- **新しいページで開く**：Markdown、HTML、PPT レポートすべてに対応しています。
- **内容のコピー**：Markdown および HTML レポートに対応していますが、PPT レポートは対応していません。
- **ダウンロード**：Markdown レポートは `.md` 形式で、HTML レポートは `.html` 形式でダウンロードできます。PPT レポートの場合は、元の PPT、PDF、ページの ZIP ファイル、および現在のページとしてのダウンロードが追加でサポートされています。
