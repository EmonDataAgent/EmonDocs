# Emon 企業微信ボットのアプリケーション連携

本ドキュメントでは、Emon プラットフォームと企業微信（WeCom）ボットを連携するための事前操作手順を説明します。システムが企業微信のユーザ名または ID を連携できるようにするため、必ず順番通りに操作を完了してください。

## 前提条件

連携を行うには、以下の条件を満たしている必要があります。
1. 企業微信の管理コンソール権限を持っていること。
2. Emon サービスのドメイン名が設定されていること。
3. 企業微信の信頼できる IP の設定に使用するため、Emon サービスのアウトバウンド IP を取得済みであること。

## 操作手順

### 1. 企業微信の自社製アプリケーションの作成

1. **管理コンソールへのログイン**：企業微信の管理者が企業微信の管理コンソールにログインし、「アプリ管理 > アプリ > 自社製」にアクセスして、アプリケーションを作成します。
2. **アプリケーション情報の設定**：アプリのロゴ、アプリ名、および公開範囲を設定します。公開範囲には、企業内でボットを使用するユーザや部門を含める必要があります。「全社」を選択することをお勧めします。

### 2. API 受信とパラメータの設定

1. **API 受信設定画面へのアクセス**：自社製アプリケーションの作成が完了すると、アプリ設定の詳細画面に自動的に遷移します。「機能 > メッセージ受信」で「API受信の設定」をクリックし、メッセージ受信サーバの設定画面に入ります。
2. **URL の取得**：以下のルールを参照して URL を取得します（例：`https://www.example.com/decision/external/api/im/config/wecom/callback`）。
   ```shell
   https://{Emon サービスのドメイン名}/{BI サービスのサフィックス}/external/api/im/config/wecom/callback
   ```
3. **認証パラメータの生成**：「ランダムに取得」をクリックすると、システムが自動的に Token と EncodingAESKey を生成します。
   > [!WARNING]
   > Token と EncodingAESKey が生成された後、保存ボタンはまだクリックしないでください。先に Emon の管理コンソールでこの 2 つの項目を入力する必要があります。

### 3. Emon 管理コンソールでの連携設定と API 受信の保存

1. **Emon 管理コンソールでの連携設定**：特権管理者として「Emon 管理コンソール > ユーザ管理 > IMユーザマッピング」にアクセスし、アプリケーション連携の設定ボタンをクリックします。前の手順で取得した Token と EncodingAESKey をダイアログに入力し、「次へ」をクリックします。
2. **API 受信の保存**：企業微信の管理コンソールに戻り、先ほどの API 受信設定を保存します。

### 4. 信頼できる IP と認証情報の設定

1. **企業の信頼できる IP の設定**：自社製アプリケーションの設定詳細画面に戻り、「開発者インターフェース > 企業の信頼できるIP」の「設定」をクリックします。ダイアログに Emon サービスのアウトバウンド IP アドレスを追加し、「確認」をクリックしてホワイトリストの設定を完了します。
2. **CorpSecret の取得**：「自社製アプリ > 設定詳細画面 > Secret」にアクセスして「表示」をクリックし、CorpSecret を取得します。
3. **企業 ID の取得**：「マイ企業 > 企業情報」にアクセスし、ページを下にスクロールして企業 ID（CorpId）を取得します。
4. **認証情報の追加完了**：「Emon 管理コンソール > ユーザ管理 > IMユーザマッピング」のダイアログ操作の続きに戻り、取得した CorpSecret と CorpId を入力します。「接続テストして保存」をクリックし、画面に「設定済み」と表示されれば設定は成功です。
