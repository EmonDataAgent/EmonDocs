## 1. 概要

### 1.1 機能概要

Agent 監視の「利用概要」モジュールは、Agent の実行状態や利用状況をグローバルに監視するデータダッシュボードです。管理者がプラットフォーム全体の運用状態を把握し、Agent の最適化、リソースの拡張、コスト管理のためのデータ基盤を提供します。

### 1.2 利用シーン

- 複数の時間軸でのフィルタリングをサポートし、異なる期間の利用トレンドを柔軟に分析します。
- 利用回数や Token 消費量に基づいて Agent をランキング化し、高価値または高消費の Agent を特定します。
- グローバルな Agent 数、利用回数、利用者数などをリアルタイムに監視します。

## 2. グローバル概要

グローバル概要は、プラットフォーム上の Agent の全体的な稼働データをすばやく確認し、プラットフォームの利用規模と活況度を直感的に把握するために使用します。

### 2.1 主要指標

現在、以下の 3 つのグローバル指標データの表示をサポートしています。

- **Agent 数**：現在のプラットフォームで作成された Agent の総数。プラットフォームの業務シーンのカバー率を反映します。
- **Agent 利用回数**：集計期間内におけるすべての Agent とユーザの合計対話回数。プラットフォームの利用アクティビティを反映します。
- **Agent 利用者数**：集計期間内に Agent を利用したユニークユーザ数。ユーザのカバー範囲を反映します。

### 2.2 時間軸フィルタ

右上の時間フィルタドロップダウンをクリックすると、以下の 5 つの時間軸でフィルタリングできます。

- **当日**：当日のリアルタイムデータを表示します。
- **過去 7 日間**：過去 7 日間の累計データを表示します。
- **過去 30 日間**：過去 30 日間の累計データを表示します（デフォルト）。
- **全期間**：プラットフォームリリース以降のすべてのデータを表示します。
- **カスタム**：開始時間と終了時間を手動で選択し、指定期間のデータを柔軟に分析します。

## 3. 利用回数ランキング

利用回数の降順でソートし、プラットフォームで利用頻度の高い上位 5 つの Agent を表示して、価値の高い業務シーンの特定を支援します。

1. **フィルタ軸**：当日、過去 7 日間、過去 30 日間、全期間、カスタム期間をサポートしています。
2. **ランキング内容**：順位順に Agent 名と対応する利用回数を表示します。
3. **応用シーン**：
   - 高頻度で利用される Agent を特定し、そのパフォーマンスとリソースを優先的に確保します。
   - 利用回数の少ない Agent を分析し、機能の最適化や提供終了の検討を行います。
   - 業務活動と組み合わせて、利用回数変動の原因を分析します。
