# Dora プラットフォーム概要

## プラットフォームのポジショニング

Dora は、エンタープライズ向けのデータエージェント（Data Agent）プラットフォームです。エンタープライズレベルのデータセキュリティ基盤とエージェントオーケストレーションエンジンを備えており、様々なビジネスシーンにおけるデータ分析、レポート、アラート、プッシュ通知などの一連のプロセスをクローズドループで実現します。

Dora は、タスクの複雑さに応じて自動的に「思考（次のアクションの計画）」し、「行動（該当スキルの呼び出し）」することでビジネスニーズに効率的に対応し、データの取得や分析をより便利でスマートなものにします。

## コアのメリット

Dora は、主にデータアナリストやデータレポートを重視する企業管理者を対象としており、以下のコアポジショニングとメリットがあります。

- **データ分析のハードル低減**：複雑な SQL 記述やレポート設定は不要で、自然言語で質問するだけでデータの詳細を取得できます。
- **分析効率の向上**：専用エージェントの設定をサポートし、構造化された分析レポートを自動生成して、定型業務を削減します。
- **ビジネスのセルフサービス化**：ユーザは自身でエージェントを利用・作成でき、パーソナライズされた分析ニーズに迅速に対応できます。

## 基本機能

データ活用能力を再利用し、ナレッジとして蓄積するため、Dora では財務、運用、営業などの業務部門ごとに専用のエージェントアシスタントを作成できます。その中でも、最も基本となる2つのコア機能があります。

### データ照会エージェント（問数類 Agent）

コードを記述したり複雑なレポートを操作したりすることなく、ユーザが自然言語の対話を通じて直接ビジネスデータを照会できるようにします。

- **インテントのスマート解析**：ユーザの質問から指標、ディメンション、時間範囲などの重要な情報を自動的に識別し、実行可能なデータクエリに変換します。
- **正確な結果の返却**：設定済みのデータソースと連携して該当データを迅速に抽出し、わかりやすいテキストやビジュアルで回答を提示します。

### レポートエージェント（報告類 Agent）

クエリ結果に基づいて、構造化された分析レポートを自動的に編成・出力し、企業管理者のデータ報告や振り返りのニーズを満たします。

- **データの自動統合**：複数回のクエリ結果や多次元データを集計し、完全なレポートフレームワークを形成します。
- **構造化された出力**：ビジネスロジックに従い、結論、データの詳細、トレンド分析などのモジュールを含む読みやすいレポートを生成します。
