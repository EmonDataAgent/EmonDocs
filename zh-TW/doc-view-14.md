## 1. 簡介

行政考勤數據助手可用於出勤與公出查詢，協助行政管理人員快速且詳細地分析出差、請假等數據，以降低數據分析門檻並節省人力投入。

## 2. 搭建步驟

### 2.1 前置操作

以管理員身分登入 Data Agent 平台，新增行政類數據與知識庫，並建立「行政考勤數據助手」Agent，進入 Agent 配置頁面。

操作步驟可參考文件：[建立 Agent](./doc-view-4.md)

### 2.2 基礎配置

1）選擇已在「管理後台 > 模型」中新增過的 AI 大模型，這裡選擇「deepseek-v3.2」模型。

2）配置詳細的系統提示詞，幫助 Agent 準確識別需求並返回正確內容，該範例提示詞參考如下：

```shell
# 角色
你是一個專業的行政考勤數據分析助手，負責根據公司2026年3月的考勤數據（包含公出與請假紀錄），回答與員工外出、請假相關的各類查詢。
```

### 2.3 新增數據

將 OrangeBI 中需要進行分析的行政考勤類分析主題數據新增至 Agent 中。

### 2.4 新增技能

選擇並新增「分析主題數據查詢」技能，重新命名為「行政考勤數據查詢」。在技能調整配置頁面中，開啟行政考勤出差數據，確保技能可以依賴該數據。

### 2.5 配置會話體驗

1）設定合適的歡迎語，例如：“嗨！我是你的考勤/公出查詢小助手，專門幫你分析公出和請假數據”

2）設定首輪推薦問題，提高問答效率，可參考下表：

| 公出查詢 | 高階主管們3月第1週出差情況？ |
| --- | --- |
| 產生部門近期的行程安排？ | |
| 哪個部門公出最為頻繁？ | |
| 長官公出的主要目的地和事由集中在哪裡？ | |
| **請假查詢** | 3月誰請假總時長超過3天？哪個部門？ |
| 3月市場部門的請假情況 | |
| 哪個層級人員的請假最多？ | |
| **綜合查詢** | 3月第1週有多少長官不在崗？請假類型佔比 |
| 公出和請假人數比例是多少？ | |
| 是否存在同一部門多人同時請假或公出的情況？ | |

### 2.6 測試與發布

上述內容配置完成後，可在右側預覽測試區域即時查看問答首頁效果，並發送對話測試 Agent 的回答準確度。測試無誤後即可儲存，並將「行政考勤數據助手」發布至工作台與獨立 URL。

## 3. 使用 Agent

管理員搭建並發布 Agent 後，一般成員使用者即可在 Data Agent 平台首頁選擇並進入 Agent，建立新會話進行提問。

與 Agent 對話以及會話操作詳情，可參考文件：[使用 Agent 2.3 與 Agent 對話](./doc-view-5.md#ddfeaa5703c886a8)
