## 1. 簡介

### 1.1 功能簡介

「全國市場潛量洞察報告員」適用於協助管理員生成硬編排格式的全國規模以上客戶市場潛量報告。報告內容涵蓋資料概覽與趨勢、市場佔有率分析等。

### 1.2 使用場景

支援生成以下分析報告：

- 全國各行業市場潛量分析報告
- 全國某行業市場潛量分析報告
- 某省份各行業潛量分析報告
- 某省份某行業潛量分析報告

## 2. 搭建步驟

### 2.1 前置作業

1. 以管理員身分登入 Data Agent 平台。
2. 增加客戶市場潛量分析相關的資料與知識庫。
3. 建立『全國市場潛量洞察報告員』Agent，並進入 Agent 配置頁面。

> [!NOTE]
> 建立 Agent 的詳細操作，請參閱 [建立Agent](https://help.fanruan.com/finereport/doc-view-4.html)。

### 2.2 基礎配置

1. 在『管理後台』>『模型』中選擇 AI 大型語言模型，例如選擇『deepseek-v3.2』模型。
2. 配置詳細的系統提示詞（Prompt），以明確角色定位、技能流程與呼叫的技能。
   
範例提示詞要求：
- 當遇到涉及報告生成的問題時，必須呼叫報告生成技能進行報告生成。
- 不允許基於已有報告直接輸出報告內容，也不允許捏造資料。
- 對報告生成進行總結時，只需提供簡要的文字描述，不要提供附件、圖表等內容。

### 2.3 增加資料

將 FineBI 中用於生成分析報告的市場潛量類儀表板資料加入至 Agent 中。

### 2.4 增加技能

選擇並增加『儀表板報告生成』技能。基於報告的硬編排特性，請選擇『上傳報告範本』，透過 AI 解析並生成一套報告範本：

#### 2.4.1 調整技能章節提示詞

請根據實際報告需求，調整 AI 生成的報告提示詞，包含：

- **全篇提示詞**：用於約束和規範整篇報告的風格與格式，並定義作用於整篇報告的欄位過濾邏輯。例如要求結論分析需使用自然語言描述、客觀展示分析內容與關鍵資料原文、關鍵資料需加粗等，同時規定時間參數、區域參數、省份參數及 Kline 名稱參數的填寫規則。
- **章節標題**：以 `【】` 作為佔位符，標註地區、行業、年份、省份等變數欄位。
- **章節內容提示詞**：透過自然語言描述圖表內容或分析方向，包含資料來源選取規則、欄位篩選規則、計算邏輯規則及圖表格式規則。

#### 2.4.2 配置章節資料

完成章節提示詞調整後，需要為每一章節配置可用資料。點擊章節標題左側按鈕，選擇在『Agent 配置頁面』>『資料』中加入的儀表板元件：

- **區域資料概覽**：選擇區域年份資料、區域省市資料、區域複合成長率、省市複合成長率。
- **區域整體資料**：選擇區域年份資料、區域省市資料。
- **行業資料**：選擇 Kline 行業資料、行業複合成長率。
- **行業整體分析**：選擇 Kline 行業資料、行業複合成長率。

選擇儀表板中相應的明細表元件後，將其分別作為表格和附件插入第三、四章節。

### 2.5 配置對話體驗

1. 設定合適的歡迎語，例如：「生成全國規模以上客戶市場潛量報告，包括資料概覽與趨勢、市場佔有率分析等」。
2. 設定首輪推薦問題以提高問答效率。

### 2.6 測試並發佈

配置完成後，可在右側預覽測試區域即時查看 Agent 首頁效果，並傳送對話以測試 Agent 的回答準確度。測試無誤後，即可儲存並將 Agent 發佈至工作台與獨立 URL。

## 3. 使用 Agent

管理員搭建並發佈 Agent 後，一般成員使用者即可在 Data Agent 平台首頁選擇並進入該 Agent，建立對話並進行提問。使用 Agent 對話的詳細資訊請參閱 [與Agent對話](https://help.fanruan.com/finereport/doc-view-5.html#ddfeaa5703c886a8)。
