# 封裝 Agent 配置

本文以建立「江蘇連鎖經營分析」封裝 Agent 為例，重點講解封裝 Agent 的配置過程。

在「管理後台 > Agent > 建立 Agent」對話框中選擇「封裝 Agent」後，即可進入 Agent 的配置頁面以完善相關設定。

## 簡介與基礎配置

### 模型選擇

請於下拉選單中選擇「管理後台 > 模型」中已新增的大語言模型。
> **注意**：模型為 Agent 提供底層的 AI 推理能力，請務必確保模型連線正常。

### 系統提示詞

請填寫規範 Agent 行為的核心指令，用以定義該智能體的角色、回答風格以及能力邊界。

## 資料與技能設定

### 資料設定

- **新增資料**：點擊「+」按鈕，您可以選擇一個或多個在「管理後台 > 資料」中已新增的分析主題或儀表板。此外，在新增資料對話框中，也支援點擊「前往資料」頁面，先新增分析主題或儀表板後，再返回進行關聯選擇。
- **預覽資料**：在新增資料對話框中，點擊左側目錄中的資料來源，即可在對話框右側快速預覽分析主題與儀表板。

### 技能設定

- **新增技能**：點擊「+」按鈕，選擇一個或多個在「管理後台 > 技能」中已發佈的官方技能。Agent 將會根據使用者的提問，自動呼叫對應的技能能力。
- **編輯技能**：技能新增成功後，支援修改技能名稱與描述，以便管理員能更快速地辨識各項技能。
- **調整技能配置**：您可以對已新增的技能調整其可用的資料，以提升技能使用的精確度與準確性。目前僅支援對以下 4 種技能進行配置調整：儀表板檢索、OR 報表查詢、分析主題資料查詢、智能報告。
- **刪除技能**：支援刪除已新增的技能，藉此調整 Agent 的能力範圍。

## 外部整合與排程任務

### MCP 整合

點擊「+」按鈕，您可以選擇一個或多個在「管理後台 > 開放整合 > 外接 MCP」中已新增的 MCP 工具，這能讓 Agent 具備使用外部資料來源與技能工具的能力。

### 定時任務

您可以為 Agent 新增定時任務，讓 Agent 在背景自動執行，並依照指定時間推送到目標使用者。
> **注意**：目前僅支援透過平台與企業微信進行推送，其他的 IM 工具（如釘釘、飛書）推送方式將在後續的版本更新中開放支援。

## 會話體驗設定

### 多輪對話與歡迎語

- **多輪對話**：此功能預設開啟且不可關閉。它支援具備上下文關聯的對話，能夠實現連續性的分析體驗。
- **歡迎語**：用於設定 Agent 首頁的互動對話內容，設定後將在右側預覽區即時呈現效果。

### 整合 IM 工具與首輪推薦問題

- **對接 IM 工具**：可以將 Agent 與企業微信等 IM 工具進行對接，藉此在其他第三方應用程式內使用該 Agent（目前支援的 IM 工具包含企業微信機器人）。
- **首輪推薦問題**：支援設定使用者首次對話時的推薦提問，以引導使用者快速上手。

## 預覽與測試

在配置的過程中，右側的「預覽」區將會即時展示 Agent 首頁的效果：
- 您可以查看 Agent 名稱與歡迎語。
- 支援在輸入框中輸入測試問題，以驗證 Agent 的回答效果。
- 支援點擊「重置對話」，清空測試對話並重新進行測試。

> **注意**：預覽區僅作為測試環境，此處的問答紀錄並不會計入歷史會話中。
