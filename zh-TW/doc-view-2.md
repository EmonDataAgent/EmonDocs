## 1. 簡介與定位

Emon 是一款企業級數據智能體（Data Agent）平台，擁有企業級數據安全底座與 Agent 編排引擎能力，能實現在不同業務場景的數據分析、報告、預警、推播等全鏈路閉環。

Emon 能夠根據任務複雜度自動「思考」（規劃下一步行動）並「行動」（呼叫對應技能），高效回應業務需求，讓數據獲取與分析更便捷、更智慧。

Emon 主要面向數據分析人員與關注數據報告的企業管理者。核心定位如下：

- **降低數據分析門檻**：無須複雜的 SQL 撰寫或報表設定，透過自然語言提問即可獲取數據詳情。
- **提升分析效率**：支援設定專屬 Agent，自動產生結構化分析報告，減少重複勞動。
- **賦能業務自助化**：使用者可自助使用或建立 Agent，快速滿足個人化分析需求。

## 2. 場景化封裝

您可以為財務、營運、銷售等不同業務線建立專屬 Agent 助手，實現數據能力的複用與沉澱。關於 Agent 的建立方法，請參閱 [創建 Agent](./doc-view-4.md)。

### 2.1 問數類 Agent

問數類 Agent 是 Emon 最基礎的核心能力，支援使用者透過自然語言對話直接查詢業務數據，無須撰寫程式碼或操作複雜報表。其優勢如下：

- **智慧解析意圖**：自動識別使用者提問中的指標、維度、時間範圍等關鍵資訊，轉化為可執行的數據查詢。
- **精準返回結果**：對接已設定的數據源，快速呼叫對應數據，以清晰的文字或視覺化形式呈現答案。
- **支援多場景查詢**：覆蓋銷售額、庫存、考勤、市場容量等常見業務分析場景，滿足日常數據獲取需求。

### 2.2 報告類 Agent

報告類 Agent 支援基於查詢結果，自動編排並輸出結構化分析報告，滿足企業管理者對數據彙報、復盤的需求。其優勢如下：

- **自動整合數據**：將多次查詢結果或多維度數據進行彙總，形成完整的報告框架。
- **結構化輸出**：按照業務邏輯產生包含結論、數據明細、趨勢分析等模組的報告，可讀性更強。
- **場景化適配**：可針對經營分析、財務彙報、銷售復盤等場景，設定專屬報告範本與輸出邏輯。
