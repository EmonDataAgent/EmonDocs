# AI 固定報告

## 簡介

AI 固定報告技能可依據預先配置的報告大綱及關聯資料源，自動整合資料與梳理邏輯，生成標準化的儀表板分析報告。此技能通常用於生成通用總結報告、歸因分析報告與對比分析報告等，同時也支援上傳本機報告範本以生成硬編排報告。以下內容將以生成通用總結報告為例說明。

## 設定步驟

### 1. 建立 Agent

建立 Agent 為設定的第一步。請參考 [建立 Agent](?:创建 Agent) 與 [封裝 Agent](?:封装 Agent) 文件，建立一個用於生成經營分析報告的 Agent，並設定好相應的模型與資料。

### 2. 新增與建立技能

第二步為替該 Agent 新增『儀表板報告生成』技能。新增技能後將進入範本選擇介面，系統支援以下三種方式建立報告範本：

1. **從空白新建**。
2. **從內建範本新建**：系統目前內建了通用總結報告、歸因分析報告與對比分析報告三套報告範本。
3. **上傳本機報告範本**：自動分析並生成報告範本，目前僅支援上傳 docx 格式檔案。

### 3. 配置編輯頁面

透過上述任一方式建立報告範本後，您將進入報告生成技能的編輯頁面。點選報告生成技能名稱右側的編輯按鈕，可修改技能名稱與描述。編輯頁面整體佈局分為左右兩大核心區域：

#### 3.1 左側區域（可用資料區）

左側區域為可用資料區，展示報告技能可引用的資料來源，為右側內容編輯提供資料支撐。此區可新增的資料均來自 Agent 設定中的資料資訊項。

可用資料區域支援區分整體與分章節資料：
- **整體資料**：在此區域新增的儀表板資料可全文件通用，支援在整篇報告的任意章節中直接呼叫，適用於貫穿全文的核心指標展示。
- **分章節資料**：針對右側編輯區域的單個章節進行獨立配置，僅允許該章節呼叫指定的儀表板資料。

此外，資料過濾功能支援根據儀表板中的過濾控制項，透過自然語言描述過濾條件，進一步精準控制技能的分析範圍。

#### 3.2 右側區域（內容編輯區）

右側區域為內容編輯區，作為提示詞編輯區域。配合格式編排與圖表等內容插入工具，此區可幫助技能正確識別並精準生成報告。

主要功能包括：
- **結構化編輯與提示詞配置**：支援以 MarkDown 格式進行內容排版與格式編輯。管理員可提前配置全篇或各章節提示詞，明確報告生成的邏輯、風格與要求，引導系統精準生成符合需求的報告內容。
- **視覺化資料插入**：支援插入可用資料區中儀表板包含的圖表、表格及附件（將儀表板中的明細表作為附件嵌入）。報告生成後，使用者可點選下載附件，實現資料與文字的深度融合。
- **全域提示詞呼叫**：支援插入全篇提示詞。該配置將作用於整篇報告，統一規範文件的整體分析框架、輸出標準與行文風格。

您還可以使用『【】』作為預留位置，標註地區、行業、年份等變數欄位。技能在執行過程中，將自動匹配使用者提問中的對應維度資訊，完成內容的動態適配與生成。
