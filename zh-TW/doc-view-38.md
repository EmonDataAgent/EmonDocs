# IM 工具對接

## 簡介與使用場景

對接 IM 工具是 Agent 跨平台觸達的能力模組。此功能支援將智能體與第三方即時通訊工具的機器人綁定，使 Agent 能夠透過第三方平台與使用者互動。
當前僅支援對接企業微信機器人，後續將放開支援對接釘釘和飛書。

常見的使用場景包含：
- **單聊場景**：使用者在企業微信中與 Emon 機器人建立單聊對話，適合個人的日常資料查詢。
- **群聊場景**：使用者在群聊中 @Emon 機器人，發起資料查詢或報告生成，適合團隊協作場景。
- **訊息卡片設計**：IM 機器人的回覆使用富文本訊息卡片，包含關鍵數字和簡潔圖表（長條圖/折線圖）。

以群聊場景為例，@Emon 機器人後發送問題，機器人將即時回答。
系統支援多輪對話，上下文始終保留，使用者可以連續追問，機器人會基於前文語境給出連貫的回答。

## 配置指南

在 Agent 中配置 IM 工具前，需以超級管理員身分進入「管理後台 > 使用者管理 > IM 使用者映射」，完成平台與 IM 工具之間的使用者映射。
操作詳情可參考文件：[IM 使用者映射](./doc-view-30.md)。

完成映射後，請依照以下步驟完成配置：

1. 進入最新版企業微信的「通訊錄 > 智能機器人」，建立一個用於連接 Emon 平台中 Agent，與其進行對話分析的機器人。
2. 在對話方塊中選擇「手動建立」，即可進入機器人建立頁面。
3. 將機器人建立頁面下拉至最下方，切換至「API 模式建立」。
4. 根據機器人用途，自訂一個便於識別的機器人名稱。
5. 在可使用的成員中，新增企業微信通訊錄中，可以與該機器人進行對話互動的成員或部門。
6. 進入 API 配置，選擇使用長連接方式，複製 Bot ID，並點選獲取 Secret，用於配置到 Emon 平台 Agent 中。
7. 進入「Agent 配置頁面 > 對接 IM 工具」，點選模組右上角的「+」按鈕，彈出「對接 IM 工具」對話方塊。
8. 選擇「企業微信機器人」，進入企業微信機器人配置頁面。
9. 將上一步獲取到的 Bot ID 和 Secret 資訊配置到 Agent 中。請注意，Bot ID 與 Bot Secret 需與企業微信機器人配置資訊完全一致，否則將導致對接失敗。
10. 配置完成後，您可在企業微信中向機器人發送測試訊息，驗證互動是否正常。
11. 若需修改配置，可在「對接 IM 工具」列表中找到對應機器人，點選「配置」重新編輯。
