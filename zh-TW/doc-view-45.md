## 1. 簡介

「權限管理」頁面為指定用戶配置 Agent 前台使用權限和管理後台操作權限，以實現細粒度的權限控制。

## 2. 設置步驟

### 2.1 設置入口

以超級管理員身份進入「管理後台>權限管理」，即可對平台中的所有用戶分配權限。

### 2.2 選擇用戶

權限管理介面左側為用戶列表。點擊某個用戶名稱後，右側面板會刷新為該用戶的權限配置內容。

### 2.3 平台權限分配

系統支援對用戶分配平台中的「Agent 前台使用」與「管理後台」兩種權限。

- Agent 前台使用：控制該用戶是否可使用前台功能。
- 管理後台：為開發用戶配置後台各模組的操作權限。

管理後台各模組的權限說明如下：

- **Agent 模組**：
  - 個人開發權限：可建立、編輯與刪除自己的 Agent。
  - 管理權限：可發佈 Agent。
- **模型模組**：
  - 個人開發權限：可增刪模型供個人使用。
  - 管理權限：可增刪公共模型。
- **Agent監管模組**：
  - 個人開發權限：可查看自己具有管理權限的 Agent 的監管資料。
  - 管理權限：無。
- **開放集成模組**：
  - 個人開發權限：可查看和使用開放集成頁面。
  - 管理權限：無。

請注意：
- 查看用戶時，不支援管理後台的權限配置。
- 個人開發權限允許用戶進行開發類操作。
- 公共管理權限允許用戶管理全域共享資源。

### 2.4 資料權限說明

平台的資料權限與 FineBI 平台保持一致。用戶在 Agent 中可存取的資料範圍，取決於其在 FineBI 平台中的資料目錄權限。

- 開發人員僅可在「管理後台>資料」中，新增自身在 FineBI 平台已獲權限的資料資源。
- 若用戶在 FineBI 平台中缺少某資料源的權限，則無法在 Agent 中查詢到該資料。
- 資料權限限制僅針對 FineBI 平台資料源。

以下資料不受資料權限限制，用戶即使缺少 FineBI 平台權限，仍可在 Agent 中正常查詢：
1. 上傳的本地 Excel 資料源。
2. 使用 Excel 資料的分析主題。
