## 1. 簡介

定時任務監管頁面可統一查看 Agent 中定時任務的推送管道、任務來源、執行紀錄和啟動狀態等資訊，並支援從任務列表逐層穿透至執行紀錄與會話紀錄。

## 2. 定時任務列表

### 2.1 定時任務資訊

支援對已設定定時任務的 Agent 進行資訊查看與編輯管理，列表展示欄位及功能如下：

| 欄位 | 說明 |
| --- | --- |
| 任務提示詞 | 發送給 Agent 的實際指令內容 |
| 執行頻率 | 任務的執行週期 |
| 推送管道 | 任務結果的推送方式 |
| 任務來源 | 任務的建立方式：「我新增的」、「Agent 內設定」 |
| 觸達用戶 | 接收該任務結果的使用者 |
| 執行紀錄 | 點擊「查看」跳轉至該任務的執行歷史 |
| 操作 | - 開始/關閉任務<br>- 編輯任務內容<br>- 刪除任務 |

### 2.2 查看執行紀錄

1. 在定時任務列表內，點擊對應任務執行紀錄的查看按鈕，即可進入該任務專屬執行紀錄詳情頁。
2. 詳情頁頂部展示任務名稱與建立來源，可透過觸達用戶、推送管道作為篩選條件，快速檢索歷史執行資料。

### 2.3 查看會話紀錄

進入定時任務執行紀錄頁面後，點擊單筆執行歷史的查看按鈕，在彈出視窗選定對應觸達用戶，頁面將自動跳轉至會話紀錄區塊，並精準定位匹配對應會話明細。
