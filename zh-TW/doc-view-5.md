## 1. 簡介

Data Agent 工作台提供了基於 Agent 的智能對話入口。使用者可以直接選擇已經設定好的 Agent，透過自然語言對話快速完成數據查詢、知識檢索以及分析報告的生成等任務。

主要使用場景包含：
- **日常數據查詢**：業務人員可直接向 Agent 提問，快速獲取銷售額、庫存或訂單等業務數據。
- **多輪對話分析**：在同一個對話中進行連續追問，以逐步深入分析業務問題。
- **歷史對話回溯**：透過左側的歷史記錄面板，快速尋找並繼續先前的分析對話。

以連鎖經營分析場景為例，您可以選擇「連鎖經營分析」Agent，並輸入問題「25 年每個省份的銷售額同比」。Agent 將會自動解析問題，從資料來源獲取數據並回傳結果。您還可支援連續追問以進一步細化分析維度（例如「其中華東區域 Top3 省份是哪些」）。

## 2. 設定步驟與工作台介紹

登入 Data Agent 後，工作台將以卡片形式展示所有已發布的 Agent。您可透過頂部的搜尋方塊快速定位目標 Agent，並點擊目標卡片以進入該 Agent 的對話介面。

如需開啟新的分析任務，請點選左側的「新聊天」按鈕，這將清空目前的對話上下文並開始全新的會話。每次點擊「新聊天」都會開啟獨立的對話上下文，Agent 並不會記憶上一次對話的內容，因此請務必在同一個對話中完成連續追問。

左側面板會顯示歷史對話記錄，點擊後即可進入歷史對話，繼續尚未完成的分析。

## 3. 與 Agent 對話互動

在介面中央的輸入框中輸入您的問題，並點擊發送按鈕（或按 Enter 鍵）送出。Agent 會自動解析您的問題意圖，呼叫對應技能，並在對話區域內返回結果。如需進一步分析，可在同一個對話中繼續輸入追問。

此外，對話糾正功能主要適用於以下兩類業務場景：
- **Agent 回覆偏差場景**：如果 Agent 輸出的內容存在錯誤，或是未符合預期，使用者可以直接提出異議、修正要求或調整指令策略。Agent 將會自動進行覆盤反思，並重新生成符合要求的結果。
- **使用者提問有誤場景**：當使用者輸入的問題有偏差，且 Agent 已進入應答生成流程時，使用者可直接在對話方塊中補發精簡、正確的問題內容。Agent 將會自動中斷原有的任務，並依照最新的問題重新給予應答。

## 4. 會話管理與工作區操作

當 Agent 輸出內容後，使用者可以點擊下方的點讚或點踩圖示，即時對會話的品質進行評價。如果 Agent 關聯的資料、知識或技能有所調整，或因網路問題未能成功輸出內容，您可以點擊「重新生成」。

此外，系統也支援多選會話內容，並透過連結分享給平台內的其他使用者查看。請注意，會話分享是以「快照」形式進行，僅分享最終的輸出結果，不會分享 Agent 的思考與分析過程。

當生成報告類 Agent 完成任務後，對話方塊右上角會自動顯示「工作區」入口，集中存放 Agent 任務過程中所產出的文件以及最終的報告文件。

工作區支援以下操作：
- **切換輸出文件**：支援 Markdown 報告、HTML 報告以及 PPT 報告。
- **切換查看模式**：支援在源碼與視覺化之間切換（適用於 Markdown、HTML 及 PPT 報告）。
- **新頁面打開**：適用於 Markdown、HTML 及 PPT 報告。
- **複製內容**：支援 Markdown 與 HTML 報告，PPT 報告不支援複製。
- **下載文件**：Markdown 報告可下載為 `.md` 格式；HTML 報告可下載為 `.html` 格式。針對 PPT 報告，還額外支援下載原始 PPT、PDF、頁面 ZIP 壓縮檔以及當前頁。
