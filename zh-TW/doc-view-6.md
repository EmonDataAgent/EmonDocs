## 1. 簡介

### 1.1 功能簡介

Agent 監管的「使用概覽」模組，是全局監控 Agent 運行狀態與使用情況的資料看板，幫助管理者掌握平台整體營運狀態，為 Agent 最佳化、資源擴容、成本管控提供資料支撐。

### 1.2 使用場景

- 支援多時間維度篩選，靈活分析不同週期的使用趨勢。
- 按使用次數、Token 消耗量對 Agent 進行排行，定位高價值或高消耗的 Agent。
- 即時監控全局 Agent 的數量、使用次數、使用者人數等。

## 2. 全局概覽

全局概覽用於快速查看平台 Agent 的整體運行資料，直觀掌握平台使用規模與熱度。

### 2.1 核心指標

目前支援查看以下三種全局指標資料：

- **Agent 數量**：目前平台已建立的 Agent 總個數，反映平台業務場景覆蓋度。
- **Agent 使用次數**：統計週期內所有 Agent 與使用者的互動總次數，體現平台使用活躍度。
- **Agent 使用人數**：統計週期內使用過 Agent 的獨立使用者數，反映使用者覆蓋範圍。

### 2.2 時間維度篩選

點選右上角時間篩選下拉選單，支援按照以下五種時間維度進行篩選：

- **當天**：查看當日即時資料。
- **近 7 天**：查看近 7 天的累計資料。
- **近 30 天**：查看近 30 天的累計資料（預設選項）。
- **所有週期**：查看平台上線以來的全部資料。
- **自訂**：手動選擇起訖時間，靈活分析指定週期的資料。

## 3. 使用次數排行

按使用次數降冪排序，展示平台中使用頻率前五名的 Agent，幫助識別高價值業務場景。

1. **篩選維度**：支援當天、近 7 天、近 30 天、所有週期、自訂時間範圍。
2. **榜單內容**：按排名展示 Agent 名稱與對應使用次數。
3. **應用場景**：
   - 識別高頻使用的 Agent，優先保障其效能與資源。
   - 分析低使用次數的 Agent，最佳化功能或評估是否下線。
   - 結合業務活動，分析使用次數波動原因。
